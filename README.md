
# SpendWise — Personal Expense Tracker

SpendWise is a personal expense tracking web application
built step by step while learning JavaScript from
fundamentals to Object-Oriented Programming (OOP).

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Git & GitHub

## Features

### Day 01 — Introduction & Setup
- Initial project structure
- Responsive dashboard
- HTML, CSS and JavaScript integration
- Browser Console practice

### Day 02 — JavaScript Fundamentals
- Income calculation
- Expense calculation
- Balance calculation
- Type conversion and template literals

### Day 03 — Conditions & Loops
- Monthly budget checking
- Budget progress visualization
- Expense category analysis
- Conditional and loop-based calculations

### Day 04 — Functions & Scope
- Reusable calculation functions
- Arrow functions
- Callback functions
- Closure practice
- Refactored dashboard rendering

### Day 05 — Arrays & Strings
- Add new transactions
- Delete transactions
- Search transactions by title or category
- Filter by transaction type
- Filter by category
- Dynamic income and expense calculations
- Automatic balance updates
- Category-wise expense analysis
- Budget monitoring
- Responsive transaction list

## Run Locally

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser.
4. Test the Add, Delete, Search and Filter features.
5. Use F12 to inspect the Browser Console.

No npm installation or build step is required.

## Current Limitations

- Transactions are stored in JavaScript memory.
- Refreshing the page restores the initial sample data.
- No database or user authentication.
- The budget is a fixed demonstration budget.
- Category totals represent the current in-memory transactions.
- Currency calculations use JavaScript Number values.
